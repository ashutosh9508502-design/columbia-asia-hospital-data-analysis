# Columbia Asia Hospital – Data Analysis & Power BI Dashboard

## 📌 Project Overview

This project focuses on analyzing **Columbia Asia Hospital** data using **SQL and Microsoft Power BI**.

The objective of the project is to transform raw hospital data into meaningful insights and interactive visualizations that can help understand hospital operations, patient information, and key performance indicators.

## 🛠️ Tools & Technologies

* **SQL** – Data querying, cleaning, and analysis
* **Microsoft Power BI** – Data visualization and interactive dashboard creation
* **Microsoft PowerPoint** – Project presentation and insights
* **Excel / CSV** – Data handling and preparation

## 📊 Project Workflow

1. Collected and understood the hospital dataset.
2. Cleaned and prepared the data for analysis.
3. Used **SQL** to query and analyze the data.
4. Connected the prepared data with **Power BI**.
5. Created interactive dashboards and visualizations.
6. Analyzed important trends and KPIs.
7. Prepared project documentation and presentation.

## 📈 Dashboard

The Power BI dashboard provides an interactive way to explore the hospital data and identify useful business insights.

### Key Areas of Analysis

* Patient-related analysis
* Hospital performance
* Key KPIs and metrics
* Trends and patterns
* Data-driven insights
* Interactive filtering and visualization
